      How do I get a public address?
      

        
With Tailscale: run tailscale funnel --bg 8080 on this computer, then use the https://….ts.net address it shows. Your Tailscale admin page needs Funnel allowed for this computer.

        
With your own domain or a fixed IP: point it at this computer and forward it (a reverse proxy such as Caddy, or your router) to port 8080.

        
Check it asks the commons to visit that address and confirms it leads back to this commons. The visit starts on this computer, so to be sure people elsewhere can reach it, open the address on a phone with Wi-Fi turned off.

      

    

    
Saving restarts the commons with the new address; people on this Wi-Fi can keep using the room address.
